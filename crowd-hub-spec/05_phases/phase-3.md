# PHASE 3 — Backlog items (on demand)

Do not start Phase 3 from a generic prompt. The user will name specific items from `04_features/F14-phase3-backlog.md`. For each requested item:
1. Write a mini-spec (purpose, behavior, edge cases, acceptance IDs `F14-<n>-AC-xx`, compliance check against `torn-rules-and-compliance.md`) and wait for `APPROVED`.
2. Build only that item. Update the checklist file with the new IDs.
3. Report with evidence.
All guardrails apply unchanged.
